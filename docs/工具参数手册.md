# 工具参数手册

> 参数的**权威定义**（类型 / 单位 / 默认值 / 范围 / 必填 / 含义）见 [参数定义](参数定义.md) —— 由
> `lib/param-spec.mjs` 生成，`npm run test:params` 双向核对。本文只讲**结构与规则**，避免同一张表维护两份。

## 1. 调用结构

一次调用 = `{ tasks: [ … ] }`（1–16 个任务，任务之间并行）。每个任务五类块，**每个工具只消费其中一部分**；
未列出的块传进来会被拒绝（不会静默忽略）：

| 工具 | 消费的块 |
|---|---|
| `shell_run` / `shell_send` | `target` / `action` / `wait` / `output` / `safety` |
| `shell_read` | `target` / `action` / `wait` / `output` |
| `shell_audit` | `target` / `action` / `output` |
| `shell_manage` | `target` / `action` / `safety`（仅 `dryrun`） |
| `shell_open` | `action`（它创建会话，没有目标） |
| `shell_state` | 不套块：只有一组扁平过滤参数 |

硬规则：

1. **操作只由 `action.kind` 表达**；参数只描述该操作的细节，不能拿参数暗示操作。
2. `action` **必填**（没有“只带 wait 等上一个命令”的用法）；每个任务只做一个操作。
3. **同一个 shell 在一次调用里只能出现一次**（重复出现整次调用被拒，请拆成多次调用）。
4. 各 kind 只接受自己的载荷；多传字段会被拒绝并列出允许的字段。

## 2. `target`

| 值 | 含义 |
|---|---|
| `mine`（默认） | 本对话创建的**全部** shell；只有一个时即该会话 |
| `*` | 全部存活 shell（必须显式传） |
| `dsh-ab12cd` / `dsh-a,dsh-b` | 显式 id（逗号分隔） |

## 3. `wait`

| kind | 含义 | 参数 | 支持工具 |
|---|---|---|---|
| `none` | **立即返回**（命令继续在后台跑）= 异步启动 | — | `shell_run` |
| `idle` | 等回到空闲/提示符（默认行为） | — | `shell_run` / `shell_read` |
| `bell` | 等到响铃（BEL） | — | `shell_run` / `shell_read` |
| `match` | 等待开始后**新出现**的输出匹配正则（JS 方言、区分大小写） | `pattern` | `shell_run` / `shell_read` |
| `exit` | 命令结束；可校验退出码。`shell_read` 上用于**已异步启动**的命令，扫缓冲里的退出码标记 | `code`（0–255）、`runId`（仅 read） | `shell_run` / `shell_read` |
| `file` | 文件出现（支持 `~`） | `path` | `shell_run` |
| `noproc` | 进程从窗格进程树消失 | `proc` | `shell_run` |
| `cpu` | 前台进程 CPU 占用低于阈值 | `threshold`（0–100） | `shell_run` |
| `foreground` | 前台命令变成指定进程 | `proc` | `shell_read` |

通用字段：`timeoutMs`（默认 30000，上限 24 小时；超时只回报“超时”，不杀进程）、
`pollMs`（默认 150，仅 `shell_run` 与 `shell_send`；`shell_send` 只有 `pollMs`）、
`runId`（仅 `shell_read` 的 `exit`：绑定到某一次 `shell_run`，其返回里带 `run=<id>`）。

## 4. `output` / `safety`

- `output.lines`：默认 20，上限 2000（tail 保留最后 N 行；since 超过 2000 行保留最后 2000 行并标注）。
- `output.showing`（仅 `shell_run`）：`tail`（默认）/ `screen` / `diff` / `summary`。
- `output.structured`（仅 `shell_run`）：返回块结构化（默认）或纯文本。
- `safety.bypassGuard`：跳过危险命令守卫（**必须同时给非空 `reason`**）。
- `safety.dryrun`：只回报会执行什么，不执行。
- `safety.lock`：`require`（默认，同 shell 写操作串行，无单独超时）/ `ignore`。
- `shell_manage` 的 `safety` **只接受 `dryrun`**（预演 close/reap/macro-rm/workspace-delete）。

## 5. 各工具的 action.kind

| 工具 | kind |
|---|---|
| `shell_open` | `open` |
| `shell_run` | `run` / `steps` / `retry` |
| `shell_send` | `send` |
| `shell_read` | `read` / `subscribe` / `unsubscribe` |
| `shell_manage` | `rename` / `resize` / `respawn` / `close` / `reap` / `idle` / `snapshot` / `snapshot-list` / `doctor` / `macro-set` / `macro-rm` / `macro-list` / `vault-list` / `macro-history` / `macro-restore` / `workspace-save` / `workspace-list` / `workspace-restore` / `workspace-delete` |
| `shell_audit` | `audit` |

各 kind 自己的参数见 [参数定义](参数定义.md#各工具的-action-参数)。

## 6. 常见错误与修法

| 现象 | 原因 | 修法 |
|---|---|---|
| `tasks 不认识的字段：session/command` | 用了参数重构之前的扁平写法 | 改成 `{ tasks: [{ target, action }] }` |
| `action 不认识的字段：watch` | `watch/unwatch` 已删除 | 用 `subscribe` / `unsubscribe` |
| `action 不认识的字段：offset` | `offset` 已删除 | 用 `matchOffset` |
| `safety 不认识的字段：confirm` | `confirm` 已删除 | 用 `bypassGuard`（+ 非空 `reason`） |
| `shell_run.action.command 在 kind=run 时必填` | 少了 command | 补上；或改用 `steps` |
| `无法等待 exit：expanded（不会注入 __DSH_EXIT__ 标记）` | 命令里含 `{{v:…}}` / `{{m:…}}` 展开 | 改用 `wait.kind="idle"`，或包一层 `sh -c "…"` |
| 命令跑完但 shell 没了 | 命令里写了 `exit` | 它会结束 shell 本身；需要提前返回用子 shell `( … )` |
| `同一个 shell 在一次调用里只能被操作一次` | 两个任务指向同一 shell | 拆成多次调用 |

## 7. 附录：枚举取值与两条硬约束

**契约**：**操作是操作，参数是参数** —— `action.kind` 表达操作，其余字段只描述该操作的细节；
不允许用参数暗示操作（例如用 `until:"done"` 表示等待）。

- `shell_manage action=reap`：只清理**闲置 ≥ 10 分钟**且「丢失但记录还在」的僵尸会话（阈值 `REAP_MIN_IDLE_MS`）。

`shell_state.state`：

| 值 | 含义 |
|---|---|
| `idle` | 空闲（前台是 shell 且窗格安静） |
| `busy` | 忙碌（前台有命令或 CPU 活跃） |
| `user-busy` | 人正在操作（AI 写入会被拒） |
| `ai-busy` | 本对话正在操作 |
| `locked` | 已锁定（手动锁或他人占用） |
| `unlocked` | 未锁定 |
| `attached` | 有客户端附着（面板/终端已连上） |

`shell_state.owner`：`mine` 本对话创建 · `others` 别的对话创建 · `panel` 人在面板创建 · `unknown` 未登记。

`shell_run.retry.mode`：`last` 直接重跑本 shell 最近一条命令 · `last-failed` 只有上一条失败时才重跑。

其余枚举：`wait.kind` 见 §3；`shell_read.read.mode`：`tail` 末尾 · `screen` 当前可见屏 · `history` 历史缓冲 ·
`since` 自上次读以来 · `diff` 与上次相比 · `summary` 摘要；`output.showing`：`tail` / `screen` / `diff` / `summary`；
`safety.lock`：`require`（串行等待）/ `ignore`；`target.sessions`：`mine` / `*` / 显式 id。

## 7. 长任务示例（异步启动 → 读增量 → 取退出码）

```jsonc
{ "tasks": [{ "action": { "kind": "open", "label": "build", "cwd": "/repo" } }] }
{ "tasks": [{ "target": { "sessions": "dsh-ab12cd" },
              "action": { "kind": "run", "command": "make -j8" },
              "wait": { "kind": "none" } }] }                      // 返回里带 run=<id>
{ "tasks": [{ "target": { "sessions": "dsh-ab12cd" },
              "action": { "kind": "read", "mode": "since" } }] }   // 反复取新增
{ "tasks": [{ "target": { "sessions": "dsh-ab12cd" },
              "action": { "kind": "read" },
              "wait": { "kind": "exit", "runId": "ab12cd34", "timeoutMs": 180000 } }] }
{ "tasks": [{ "target": { "sessions": "dsh-ab12cd" }, "action": { "kind": "close" } }] }
```
