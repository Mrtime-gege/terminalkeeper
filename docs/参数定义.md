# 参数定义（自动生成）

> 本文件由 `lib/param-spec.mjs` 生成，**不要手改**。改定义后运行 `npm run docs:params` 重新生成。
> 代码、工具说明与测试都以 `PARAM_SPEC` 为准：新增参数先在这里定义，再实现。

## 工具级参数（所有 `tasks` 型工具）

| 参数 | 类型 | 单位 | 默认 | 范围 | 必填 | 含义 | 备注 |
|---|---|---|---|---|---|---|---|
| `tasks` | array | 个 | — | 1 – 16 | 是 | 一次调用里的任务列表；任务之间并行执行，同一 shell 在一次调用里只能出现一次。 | 超过 16 个直接拒绝；重复出现同一个 shell 会整次调用被拒。 |
| `concurrency` | number | 个 | 4 | 1 – 8 | 否 | 任务之间、任务内各会话之间的最大并行数。 | 超过上限夹到 8；1 = 完全串行。 |

## `wait` 块

| 参数 | 类型 | 单位 | 默认 | 范围 | 必填 | 含义 | 备注 |
|---|---|---|---|---|---|---|---|
| `kind` | enum |  | idle | none / idle / bell / match / exit / file / noproc / cpu / foreground | 否 | 等待条件：none = 立即返回（异步启动）；idle = 等回到空闲/提示符；bell = 等响铃；match = 新输出匹配正则；exit = 命令结束（可校验退出码）；file = 文件出现；noproc = 进程消失；cpu = 前台进程 CPU 低于阈值；foreground = 前台变成指定进程。 | shell_run 支持 none/idle/bell/match/exit/file/noproc/cpu；shell_read 支持 idle/bell/match/exit/foreground；shell_send 只有 pollMs。 |
| `timeoutMs` | number | ms | 30000 | 0 – 86400000 | 否 | 等待条件最多等多久；超时只回报“超时”，不杀进程。 | 上限 24 小时；两分钟以上的命令请显式给值。shell_run / shell_read 支持。 |
| `pollMs` | number | ms | 150 | 20 – 100000 | 否 | 轮询间隔（shell_run 检查条件、shell_send 等屏幕稳定的间隔）。 | shell_run / shell_send 支持；shell_read 不支持。 |
| `code` | number | 退出码 | — | 0 – 255 | 否 | kind=exit 时同时校验退出码；不符会立即回报 `exit=N ≠ 期望`。 | 仅 kind=exit 有意义。 |
| `runId` | string |  | — | shell_run 返回的 run=<id> | 否 | kind=exit 时绑定到某一次具体的 shell_run（多命令先后跑时不会认错退出码）。 | 仅 shell_read 支持；不传则绑定本 shell 最近一次 shell_run。 |
| `pattern` | string |  | — | JS 正则 | 否 | kind=match 时要匹配的正则（区分大小写，只匹配等待开始后新出现的输出）。 | 仅 kind=match；正则非法会直接拒绝。 |
| `path` | string |  | — | 文件路径（支持 ~） | 否 | kind=file 时要等的文件。 | 仅 kind=file。 |
| `proc` | string |  | — | 进程名 | 否 | kind=noproc 等该进程从窗格进程树消失；kind=foreground 等前台变成该进程。 | noproc 仅 shell_run；foreground 仅 shell_read。 |
| `threshold` | number | % | — | 0 – 100 | 否 | kind=cpu 时前台进程 CPU 占用低于该阈值即到达。 | 仅 shell_run。 |

## `output` 块

| 参数 | 类型 | 单位 | 默认 | 范围 | 必填 | 含义 | 备注 |
|---|---|---|---|---|---|---|---|
| `lines` | number | 行 | 20 | 0 – 2000 | 否 | 返回多少行；tail 保留**最后** N 行；since 的新增超过 2000 行会保留最后 2000 行并标注丢弃量。 | 上限 2000；history 模式另有更大的读法。 |
| `showing` | enum |  | tail | tail / screen / diff / summary | 否 | 返回形状：tail 末尾 / screen 当前可见屏 / diff 与上次读取相比 / summary 末尾若干行并标注总行数。 | 仅 shell_run 支持；shell_read 用 action.mode。 |
| `structured` | boolean |  | true | true / false | 否 | true = 按块结构化返回（汇总头 + 每任务一段）；false = 一段纯文本。 | 仅 shell_run。 |

## `safety` 块

| 参数 | 类型 | 单位 | 默认 | 范围 | 必填 | 含义 | 备注 |
|---|---|---|---|---|---|---|---|
| `bypassGuard` | boolean |  | false | true / false | 否 | 跳过危险命令守卫（必须同时给非空 reason；审计记 bypass-guard）。 | 只在用户明确要求时用；无 reason 会被拒绝。shell_run / shell_send 支持。 |
| `dryrun` | boolean |  | false | true / false | 否 | 只回报将要执行什么，不真正执行。 | shell_run / shell_send / shell_manage（仅破坏性动作）支持。 |
| `lock` | enum |  | require | require / ignore | 否 | require = 同一 shell 的写操作串行（默认，无单独超时）；ignore = 不等待会话锁。 | 人工锁定与它无关：被人工锁定的 shell 会立刻 REFUSED。 |
| `reason` | string |  |  | 任意文本 | 否 | 写进审计的原因（bypassGuard 时必填）。 | 会进审计记录。 |
| `force` | boolean |  | false | true / false | 否 | 引用库未解密时是否强制继续（口令加密的组仍会被拒绝）。 | 只影响引用展开路径。 |
