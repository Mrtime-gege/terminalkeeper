## 1. 使用细节
> 参数的**权威定义**见 [工具与参数](工具与参数.md#p2)（由 `lib/param-spec.mjs` 生成）；架构与数据布局见 [架构与实现](架构与实现.md#p1)。
> 本文只讲「怎么用、要注意什么」，不复述实现。

<a id="p1-1"></a>
### 1. 它是什么

一个 DSH 插件：私有 tmux 服务端持有若干**持久 shell**，关页面 / 换对话 / 热重载 / 重启 DSH 都不丢；
另有 7 个模型工具、一个真终端面板、一条防篡改审计链、一个只能由人写入的引用库（vault）。

<a id="p1-2"></a>
### 2. 安装、升级、卸载

```sh
npx -y terminalkeeper install [--profile web]   # 登记进 profile、装依赖、检查 tmux
npx -y terminalkeeper doctor                    # 体检
npx -y terminalkeeper uninstall                 # 反向移除（数据保留）
```

- 装完/升级完 **重启一次 `dsh web`**（宿主半是普通 JS，不在热重载范围）。
- 彻底清理：`node purge-all.mjs`（默认 dry-run）→ 确认后加 `--yes`；或 `npx -y terminalkeeper purge-data --dry-run/--yes`。
- 备份/恢复：`terminalkeeper backup` / `restore`（默认落在 `$HOME`，绝不写进仓库）。

<a id="p1-3"></a>
### 3. 配置

两种入口：**设置页**（面板 ⚙，7 个分区）与 `cordis.patch.yml` 的 `config`。设置页写入的覆盖值优先。
分区：功能开关 / 终端与会话 / 界面与外观 / 面板与显示 / 审计与留痕 / 安全与授权 / 服务端与集成。

常用项与默认值：

| 键 | 默认 | 说明 |
|---|---|---|
| `shell` / `shellArgs` | `bash` / `[]` | 新会话用的 shell 与参数（写进 tmux 服务端配置，改了要重启） |
| `cols` / `rows` | 120 / 32 | 新会话尺寸（范围 20–1000 × 5–500） |
| `historyLimit` | 100000 | 每会话保留的历史行数（改了要重启） |
| `maxSessions` | 8 | 全局存活上限（1–64）；超出后新建整批拒绝 |
| `idleClose` / `idleCloseMinutes` | `false` / 60 | 空闲自动回收总开关与兜底分钟数 |
| `guardDangerousCommands` | `true` | 危险命令守卫（启发式，不是沙箱） |
| `redactSecrets` | `true` | 输出打码 |
| `requireConsent` | `true` | 首次使用前的授权门 |
| `audit` / `auditRetentionDays` | `true` / 30 | 审计链与保留期 |
| `captureOutput` | `true` | 终端输出留痕（默认上限 64 MiB/会话） |
| `replayCapture` | `true` | 屏幕帧回放录制（占磁盘，可关） |
| `panelPollMs` | 800 | 面板轮询节奏（有 SSE 推送时只作兜底） |
| `allowedHosts` | `[]` | 面板 HTTP 允许的额外 Host（默认只认回环） |

**清理执行二次确认**：设置页的「立即执行」第一次点击只进入确认态，第二次才真正按策略删除/轮转文件；API 上对应 `action:'apply', confirm:true`。

**安全项二次确认**：`guardDangerousCommands` / `requireConsent` / `audit` / `redactSecrets` / `auditDir` / `allowedHosts` / `shell` / `shellArgs` 等影响安全边界的项，值变化时第一次保存会被拒绝（409 `needConfirm`），再保存一次即确认；`auditDir` 必须是绝对路径且不能含 `..`。

**立即生效 vs 重启**：改尺寸、空闲、审计、开关、面板外观等下次调用/渲染即生效；
`shell` / `shellArgs` / `defaultTerminal` / `historyLimit` / `extendedKeys` 写在 tmux 服务端配置里，**必须重启 dsh** 才重建服务端。

<a id="p1-4"></a>
### 4. 面板（人这一侧）

右下角胶囊 `>_ N 🔒`：N 是会话数，🔒 表示当前锁着（点一下解锁即可直接打字）。

- **列表**：排序 / 多条件筛选 / 批量操作（重开、统一尺寸、锁定、关闭）/ 台账。
- **终端**：真终端（`sudo`、`vim`、REPL、补全、历史全通）；抓屏 SSE 推送，断线自动退回轮询；
  面板内搜索 `Ctrl+F`（`Aa` 区分大小写、`.*` 正则、`◐` 按文字/背景颜色 + 目标色与容差）；`Ctrl+Shift+↑/↓` 切换会话；`F2` 改名；`Esc` 关浮层（没有浮层时按键照常送给终端）。
  完整键位见 [键位](#p2)。
- **详情（8 个页签）**：总览 / 概览 / 运行 / 安全 / 事件记录 / 引用库事件 / 日志审计 / 键位帮助。
  总览看状态与指标；运行看启动流程与参数；安全看审计链、镜像、审批；后三个页签是记录与帮助。
- **锁**：面板锁定后，AI 对该会话的任何操作一律 `REFUSED`（不会等待）。

<a id="p1-5"></a>
### 5. 工具（AI 这一侧）

所有工具共用 `{ tasks: [{ target, action, wait, output, safety }] }` 结构：

- `target.sessions`：`mine`（本对话创建的全部 shell）/ `*`（全部存活）/ 具体 id（逗号分隔）。
- `action.kind`：一个任务只做一件事；**同一个 shell 在一次调用里只能出现一次**（重复直接整次拒绝）。
- 参数含义与默认值：见 [工具与参数](工具与参数.md#p2)。

| 工具 | 用途 |
|---|---|
| `shell_open` | 开持久 shell（label/cwd/cols/rows/idleMinutes/watch/from） |
| `shell_run` | 跑命令：`run`（配 command）/ `steps`（短交互序列）/ `retry` |
| `shell_send` | 像人一样输入：`preKeys → text → keys`（text 不自动回车） |
| `shell_read` | 读屏幕/历史/增量；`subscribe` / `unsubscribe` 订阅新输出 |
| `shell_manage` | 生命周期与资源：rename/resize/respawn/close/reap/idle/snapshot(-list)/doctor/宏/工作区/vault-list |
| `shell_state` | 看会话状态与归属（只读，扁平过滤参数） |
| `shell_audit` | 读审计链（按 actor/source/days 过滤，可 export） |

**长任务的推荐流程**（异步启动 → 期间读增量 → 事后取退出码）：

```jsonc
// 1) 开
{ "tasks": [{ "action": { "kind": "open", "label": "build", "cwd": "/repo" } }] }
// 2) 异步启动（立即返回，返回里带 run=<id>）
{ "tasks": [{ "target": { "sessions": "dsh-ab12cd" },
              "action": { "kind": "run", "command": "make -j8" },
              "wait": { "kind": "none" } }] }
// 3) 期间读增量（不要读整屏）
{ "tasks": [{ "target": { "sessions": "dsh-ab12cd" },
              "action": { "kind": "read", "mode": "since" } }] }
// 4) 结束后取退出码（runId 绑定到第 2 步那次运行）
{ "tasks": [{ "target": { "sessions": "dsh-ab12cd" },
              "action": { "kind": "read" },
              "wait": { "kind": "exit", "runId": "ab12cd34", "timeoutMs": 180000 } }] }
// 5) 关
{ "tasks": [{ "target": { "sessions": "dsh-ab12cd" }, "action": { "kind": "close" } }] }
```

**三个必须知道的坑**：

1. 命令里**不要写 `exit`** —— 它结束的是 shell 本身，退出码标记就永远不会出现；需要提前返回用子 shell `( … )`。
2. 含 `{{v:…}}` / `{{m:…}}` 的命令**不会**被包装（拿不到退出码标记）：要退出码用 `wait.kind="idle"`，或包一层 `sh -c "…"`。
3. 同一 shell 在一次调用里重复出现 = 整次拒绝；多任务请拆成多次调用。

<a id="p1-6"></a>
### 6. 引用库（vault）

**只有人能写**：面板「🔑 引用库」或 CLI；AI 没有写入入口，只能引用键名。

- **组**：新键默认落在「默认引用组」。每组三种模式：不加密 / 简单混淆（设备密钥，只防明文被全盘搜到）/ 口令加密（需要口令解锁）。
  **锁定组**：不列键名、不能引用、不能迁移或删除；先在组那一行点「解密」。
- **条目**：值 / 类型（`secret` 等）/ **剩余可用次数** / 有效期至 / 备注。
  - 剩余可用次数是**输入框**（不再是复选框）：填 N = 还能再用 N 次；**1 = 一次性**（用掉即焚）；留空 = 不限。

  - 额度用尽会自动销毁该键，并留下**烧伤标记**；重建同名键需要显式确认（`reuseName:true`）。
  - **改值不重置已用次数**（次数是托管额度，不是值的属性）。
  - 有效期至：到点自动焚毁；留空 = 永不过期。
- **AI 的用法（严格）**：AI 只能做**整条裸引用** —— 整条输入就是 `{{v:键名}}`（典型是 `shell_run` 的 `steps[].send`，
  把值直接喂给程序的标准输入提示，如 `read -s pw` / `sudo -S`）。
  `shell_manage action=vault-list` 只回**键名 + 额度/已用次数**，永远不含值。
  面板的 `GET /vault-list` 也不返回值；要取某个值必须点该行「复制值」（单键 `POST /vault-get`，
  每次读取都记一条 `read-value` 审计）。同源脚本仍可逐个取，只是从“一次拉全”变成 N 次可审计请求。
  **把 `{{v:键名}}` 嵌进命令**（`curl -H "…{{v:key}}"`、`echo`、管道）会被直接拒绝：值一旦进 AI 可加工的管线，
  任何变换输出（base64/rev/od）都能绕过打码（转换外泄，实测）。需要的话由人在面板「引用库」旁亲自输入。
  宏由人写时可嵌 `{{v:}}`（宏体全量入链）；AI 写的宏展开时同样按裸引用规则校验。
- **打码边界（诚实说明）**：输出里出现值会被打码，但**加工管道能绕过**（`base64`/`rev`/`od` 等变形成非字面值），
  `output/` 留痕是原始字节流，值进过屏幕就会进留痕；同权限进程能直接读 `vault.json`（0600 只挡别的用户）。
  要真正保密，唯一办法是别把重要凭据交给 AI 可达的 shell。
- CLI：`terminalkeeper vault list|set|rm`（写入的是同一份 vault.json）。

<a id="p1-7"></a>
### 7. 宏（可复用的命令片段）

- 存：`shell_manage action=macro-set`（`name` / `text` / `scope=global|conversation|shell` / `submit`）。
- **用**：在 `shell_run` 的命令里写 `{{m:宏名}}` —— 直接把宏名当命令敲**不会**执行。
- `submit:true` 表示展开后自动回车；宏里可以嵌 `{{v:…}}`（但含引用的宏展开后同样拿不到退出码标记）。
- 所有宏写入、修改、还原都会进审计链。
- **AI 侧不能创建或展开含 `{{v:…}}` 的宏**（会绕过「只能整条裸引用」）；这类宏只能由人在面板里创建。
- **多行值不能作为裸引用注入**：换行会被 shell 拆成多条命令（实测第二行会被执行）；多行内容请手动复制，或存成文件后引用路径。
- **裸引用不是保密边界**：把值喂给会回显的程序（如 `cat`）仍会让值出现在屏幕上；打码只覆盖“引用注入产生的行”，程序自打的明文按已泄露对待。
- **单值上限 16 KiB**：密码、令牌、PEM/证书、环境变量块都够用；更大的内容请加密落文件，用路径引用。
- **总量上限**：总键数 2000、每组 500 键、明文总量 5 MiB；超限时写入返回 400（防误导入撑爆 vault/备份）。

<a id="p1-8"></a>
### 8. 工作区与快照

- **工作区**：`workspace-save name` 存一组会话布局；`workspace-list` 查看；`workspace-restore name` **会新开 shell**（不是原地恢复）；`workspace-delete name` 删除。
- **快照**：`snapshot` 手动存（按会话 id）；`snapshot-list` 列出已有快照；`shell_open { from: "<旧会话 id>" }` 复活。
  `close` / 空闲回收 / `resize` / `rename` 也会**自动留快照**（reason 字段注明），但只恢复屏面与历史，**不恢复进程**。

<a id="p1-9"></a>
### 9. 审计与留痕

- 每天一个文件：`<数据目录>/audit/audit-YYYY-MM-DD.jsonl`，逐条封链（SHA-256 串接）。
- 工具调用、每次送进 shell 的输入、会话生命周期、设置变更、授权决定、宏写入、手动删除（purge）都在里面。
- 审计链会周期性生成**签名检查点**，可配镜像目录异地保存；断链 / 改字节 / 调顺序都会被发现。
- 终端输出留痕是另外的 `output/*.log`（原始字节流，容量可配），close 时把 `sha256+bytes` 写进审计。
- 查看：面板「日志审计」页签 / `shell_audit` 工具 / `terminalkeeper verify-audit <目录>` / `purge-audit`（删除会入链见证）。
- 审计时间戳按 **UTC** 显示（末尾 `Z`）；`shell_audit` 的 `output.lines` 是**返回记录条数**（默认 50、最大 500，取最后 N 条），更早记录仍在链上，可调大 `lines` 或用 `export:true` 导出。

<a id="p1-10"></a>
### 10. HTTP API（面板用的那套）

路由挂在 `/plugins/shell/*` 下，**没有独立鉴权**，防线是 DSH 的浏览器会话 + 本地围栏（Host 必须回环、拒绝跨站、写请求必须 `Content-Type: application/json`）。
被拒的请求会记进面板「闸门拒绝」。

路由一览（按用途）：

- 会话：`/list` `/new` `/kill` `/rename` `/resize` `/respawn` `/screen` `/stream` `/keys` `/busy` `/lock`
- 「我」相关：`/actors` `/consent` `/settings` `/status` `/diagnose` `/probe` `/notice` `/debugctl`
- 审计：`/audit` `/audit-files` `/audit-size` `/chain` `/supervisor` `/panel-retention`
- 回放：`/replay` `/replays`
- 宏：`/macro-list` `/macro-set` `/macro-rm`
- 引用库：`/vault-list` `/vault-set` `/vault-rm` `/vault-groups` `/vault-group-set` `/vault-mode` `/vault-move` `/vault-lock` `/vault-unlock` `/vault-devkey` `/vault-history`

<a id="p1-11"></a>
### 11. 什么时候需要重启

| 情况 | 要做的事 |
|---|---|
| 改了插件代码（`lib/client.js`） | 面板热重载即可（浏览器端） |
| 改了插件代码（`lib/index.js` 等宿主半） | 重启 `dsh web` |
| 升级插件版本 | `install` 后重启 |
| 改了 `shell`/`shellArgs`/`historyLimit`/`extendedKeys` | 重启（要重建 tmux 服务端） |
| 面板提示「DSH 的代码比面板旧 / 面板比 DSH 旧」 | 重启 `dsh web` |

<a id="p1-12"></a>
### 12. 已知限制（不假装能挡）

- 引用库不是磁盘加密：同权限进程可读 `vault.json`；值进过屏幕就会进留痕。
- 值经加工管道可被 AI 还原（base64/rev 等）——计数只能限制次数，挡不住第一次。
- 危险命令守卫是启发式减速带：它拦根/家/通配删除、`mkfs`、`dd` 写块设备、`curl|sh`、`tmux kill-server`、`npm publish`、`git push --force` 等，**`rm -rf /tmp/x` 这类普通清理不拦**。
- 订阅只适合行式输出；`top`/`vim` 这类全屏 TUI 订阅只会得到重绘噪音（用 `read` 读当前屏）。
- 服务绑到 `0.0.0.0` 时本地围栏无法判断是否本机（DNS rebinding 面），面板会明确标出降级。

## 2. 键位

> 当前为固定绑定；自定义键位在规划中。焦点不在面板时，按键照常交给终端。

面板快捷键：

| 动作 | 默认键 |
|---|---|
| 新建 shell | `Ctrl+Shift+T` |
| 关闭当前 shell | `Ctrl+Shift+W` |
| 上一个 / 下一个 shell | `Ctrl+Shift+↑ / ↓` |
| 跳到第 N 个 shell | `Ctrl+Shift+1…9` |
| 会话选择器 | `Ctrl+Shift+P` |
| 详情 | `Ctrl+Shift+D` |
| 授权管理 | `Ctrl+Shift+A` |
| 引用库 | `Ctrl+Shift+K` |
| 日志管理 | `Ctrl+Shift+L` |
| 锁定 / 解锁 | `Ctrl+Shift+M` |
| 重命名当前 shell | `F2` |
| 面板内搜索 | `Ctrl+F` |
| 关闭浮层 | `Esc` |

终端键位与 tmux 直通（`^b` 前缀等）不改动；完整三组键位表在面板「详情 → 键位帮助」。
